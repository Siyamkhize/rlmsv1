# Sync coordination guard and retry removal

This change adds a concurrency guard to `persistent_sync_service.dart` and removes the duplicate retry layer from `manual_clocking_evidence_sync_service.dart`. The guard prevents overlapping sync operations by checking `_isSyncing` before starting and clearing it in a finally block. The evidence sync service now makes direct HTTP calls with a 10-second timeout instead of wrapping them in application-level retry logic.

**Watch for:** None — all issues from the first pass have been resolved.

**Verdict**: APPROVED

## High-level view

The `_isSyncing` flag is checked before being set, set immediately after the check passes, and cleared in a finally block that covers the entire sync operation. `_makeRequestWithRetry()` and `_isRetryableError()` have been deleted. `syncToServer()` uses `http.post(...).timeout(const Duration(seconds: 10))` directly. The `dart:math` import remains because `Random.secure()` is still used. Public API signatures are unchanged. Flutter analyze produced 0 errors.
